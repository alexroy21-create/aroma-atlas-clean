How to Host on GitHub Pages (Free)

▼

Hosting on GitHub Pages gives your app a permanent URL, makes Gemini work, and lets you access it from any device. It's free and takes 2 minutes.

  1. Go to github.com and create a free account (or log in)
  2. Click + → New Repository. Name it aroma-atlas. Set it to Public. Click Create repository
  3. Click uploading an existing file, then drag your Aroma Atlas HTML file in. Rename it to index.html before uploading
  4. Click Commit changes
  5. Go to Settings → Pages → Source and select Deploy from branch → main
  6. Wait ~60 seconds, then your app is live at yourusername.github.io/aroma-atlas
  7. Open that URL on your phone — add it to your Home Screen for an app-like experience
  8. Paste your Groq API key in Settings above — The AI will now work
To update the app in future: go to your GitHub repo, click index.html, click the pencil icon, then drag the new file in — or use the Upload files button. Changes go live in under a minute.
